# Files

- [@ulabase/cli](cli.md) - CLI tool and library for idempotent, file-driven configuration of Ulabase services. Provides the ulabase command, admin and service clients, session management, environment variable secret resolution, and a step-based setup runner.
- [@ulabase/kit-ng](kit-ng.md) - Angular adapter for Ulabase Kit. Provides RhAuthService with signals, route guards, HTTP interceptor, payments service, and cart service for Angular applications.
- [@ulabase/kit-react](kit-react.md) - React adapter for Ulabase Kit. Provides context, hooks, and route guards for authentication, payments, and cart, plus a /next subpath for Next.js SSR support.
- [@ulabase/kit-vue](kit-vue.md) - Vue adapter for Ulabase Kit. Provides composables and navigation guards for auth, payments, and cart, plus a /nuxt subpath for Nuxt SSR support.
- [@ulabase/kit](kit.md) - Core framework-agnostic package with zero dependencies. Provides authentication, token management, team operations, consents gating, password reset, payments, orders, cart, and money formatting.
